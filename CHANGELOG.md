# Changelog

All notable changes to this project are documented in this file.

## 0.2.0 - 2026-09-28

### Changed

- Moved the canonical Agent Skill payload to skills/kiro-lite-specs.
- Corrected GitHub installation examples to use the real repository address.
- Added complete npm repository, issue tracker, homepage, and discovery metadata.
- Documented one-shot, dependency-based, manual, project, and user installation flows.

### Added

- End-to-end package tests that pack, install, execute, and verify both platform targets.
- User-scope installation coverage.
- Cross-platform GitHub Actions checks for Windows and Ubuntu.

## 0.1.0 - 2026-09-24

- Initial GitHub distribution with the installer, validator, templates, and Agent Skill.
